# 천하일통 — 프로토타입 v0.1

상세 기획서의 1단계 "프로토타입"(12성 축소판, 내정·전투 코어)을 웹 기술로 구현한 것이다.
휴대폰 세로 화면 기준이며, 나중에 Capacitor 등으로 감싸 앱스토어에 낼 수 있다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/index.html 단일 파일 빌드
npm test           # 단위 테스트 + AI 자동 시뮬레이션 (vitest)
npm run e2e        # 모바일 화면 E2E (Playwright, 빌드 후 실행)
```

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/core/data.ts` | 시나리오 「관도의 각오」(200년): 12성, 6세력, 장수 47명 (능력치는 가안) |
| `src/core/commands.ts` | 내정 7종, 인사(탐색·등용·이동·수송), 외교(동맹·예물), 계략(이간·유언비어) |
| `src/core/battle.ts` | 라운드제 야전·공성 (돌격·화계·방어·퇴각, 일기토, 수상전, 모의전 승률) |
| `src/core/turn.ts` | 턴 진행: 위임 내정, AI 세력, 경제, 재해(예고→발생), 충성·출분, 동맹 기한, 승패 |
| `src/core/save.ts` | 저장(localStorage)·불러오기, 되돌리기 3턴 |
| `src/ui/` | 모바일 UI (지도, 도시 카드, 명령, 전투, 월간 보고, 기록) |
| `tests/` | 단위 테스트, 30년 AI 자동 시뮬레이션 |
| `e2e/` | Playwright 모바일 E2E (390×844, 360×740) |
| `scripts/balance-probe.test.ts` | 밸런스 측정용 (병력비별 공격 승률 등) |

코어(`src/core`)는 화면과 분리된 순수 로직이고, 시드를 고정한 난수만 쓰므로 같은 시드는 같은 결과를 낸다.
