## 자체 점검으로 고친 문제

- 세로 화면에서 전투 무대 성벽(x=4.3)이 화면 밖, 진형이 하단 UI에 가려짐 → 보이는 영역(약 x ±2.8, y −2.1~+4.3)에 맞게 재배치
- 도시 카드가 화면의 43%를 차지해 지도가 좁음 → 600px로 줄이고 스크롤
- 셰이더 함수 이름 `noise`가 HLSL 내장 함수와 겹침 → 이름 변경

## 검증하지 못한 것

- Unity 에디터·실기기에서의 실제 실행 (이 작업 환경에 Unity를 설치할 수 없음)
- 셰이더 실제 컴파일 (Built-in RP 문법 기준으로 작성·검토만 함)
- 프레임 속도, 메모리
