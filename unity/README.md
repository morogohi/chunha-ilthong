# 천하일통 — Unity 버전 v0.2

웹 프로토타입(v0.1)의 게임 로직을 C#으로 옮기고, Unity에서 수묵 연출을 붙인 모바일(세로) 버전이다.
그림 파일이 하나도 없다. 모든 그래픽은 코드와 셰이더로 그린다 (원화가 확정되면 교체).

## 여는 법 (Unity 6 기준)

1. Unity Hub › **Add › Add project from disk** 에서 이 폴더(`ChunhaUnity`)를 고른다.
   에디터 버전은 Unity 6.3 LTS(`ProjectSettings/ProjectVersion.txt` = 6000.3.6f1)로 맞춰 두었다. 6000.0 이상이면 열린다. 렌더 파이프라인은 Built-in이다.
2. 처음 열면 `천하일통 › 프로젝트 설정` 이 자동으로 한 번 실행된다.
   씬(`Assets/Scenes/Main.unity`) 생성, 빌드 목록 등록, 세로 화면, 앱 이름, 입력 방식 설정을 한다.
   자동으로 실행되지 않았다면 상단 메뉴 **천하일통 › 프로젝트 설정** 을 누른다.
3. 입력 방식을 바꿨다는 창이 뜨면 Unity를 한 번 다시 시작한다.
4. Game 창의 해상도를 세로(예: 1080×1920 또는 iPhone 14)로 맞추고 **Play** 를 누른다.

> 한글 글꼴(`Resources/Fonts/KoreanFont.otf`, Noto Sans CJK KR에서 한글만 잘라 낸 1.7MB, OFL 라이선스)이 들어 있다.
> 다른 글꼴을 쓰려면 같은 이름으로 바꿔 넣으면 된다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `Assets/Chunha/Core` | 게임 로직 (UnityEngine 참조 없음). 웹 프로토타입과 같은 시드에서 같은 결과를 낸다 |
| `Assets/Chunha/Presentation` | Unity 표현 계층: GameRoot(흐름), Map, Battle, FX, UI |
| `Assets/Chunha/Resources/Shaders` | 수묵 셰이더 3종 |
| `Assets/Chunha/Editor` | 프로젝트 설정 메뉴 |
| `Tests/Chunha.Tests` | .NET 테스트: 단위, AI 30년 시뮬레이션, 웹 프로토타입과의 결과 일치 |
| `Tests/UnityStubCheck` | Unity 없이 스크립트 컴파일을 검사하는 프로젝트 (UnityEngine API 대체 선언) |

## 테스트 (Unity 없이)

```bash
cd Tests/Chunha.Tests && dotnet run -c Release     # 44개 테스트
cd Tests/UnityStubCheck && dotnet build             # Presentation·Editor 스크립트 컴파일 검사
cd Tests/AudioRender && dotnet run -- out           # 합성 사운드를 WAV로 렌더해 클리핑 검사
```

## 조작

- 지도: 끌어서 이동, 두 손가락으로 확대·축소 (PC는 마우스 휠), 도시를 눌러 선택
- 도시 카드: 내정·인사·외교·계략·출진·수송, 운영 방침(직할/개발/군비/진흥/균형)
- 전투: 돌격·화계·방어·퇴각 선택 또는 모의전으로 끝내기, 끝나면 포로 등용·해방·처형
- 하단: 기록(나만의 삼국사), 되돌리기(3턴), 턴 종료

## 빌드

- 로컬: File › Build Profiles 에서 Android 또는 iOS 를 고르고 빌드한다. 번들 ID는 `com.chunha.ilthong`, 버전 0.2.0.
- CI: GitHub Actions 의 **Unity build (manual)** 워크플로. 저장소 Secrets 에 `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD` 가 필요하다. 진입점은 `Chunha.EditorTools.ChunhaSetup.CIBuild`.

## 알려진 한계 (v0.2)

- Unity 에디터에서 직접 실행해 확인하지 못했다. 코어는 .NET에서 검증했고, Unity 스크립트는 대체 선언으로 컴파일만 검사했다. 첫 실행 때 화면을 한 번 훑어보고 어긋난 배치를 잡아야 한다.
- 장수 초상화는 먹 실루엣이다 (원화 확정 후 교체).
- AI가 플레이어 성을 공격하면 자동으로 결판이 난다.
- 클라우드 저장·랭킹·광고·결제가 없다 (출시 체크리스트 참고).
