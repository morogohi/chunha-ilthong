# 출시·화제성 계획

## 현실적인 목표

앱스토어 "전체 매출/인기 10위"는 대형 퍼블리셔가 광고비로 다투는 자리라 개발만으로 약속할 수 없다.
대신 **카테고리 차트(게임 › 전략, 한국 유료/무료) 10위 안**과 **"오늘의 게임"·"에디터 추천" 피처드**를 1차 목표로 잡는다.
한국 앱스토어 전략 카테고리는 상위권 진입에 필요한 일 다운로드 수가 전체 차트보다 훨씬 적어, 출시 첫 주 집중이 효과가 크다.

## 왜 눈에 띌 수 있나 (상품성 근거)

| 강점 | 근거 |
| --- | --- |
| 첫인상 | 수묵 셰이더(흐르는 강, 번지는 세력 먹, 계절 색)로 스크린샷 한 장에서 차별화 — 삼국지류 대부분이 실사풍·애니풍 |
| 향수 + 짧은 세션 | 고전 PC 삼국지 세대(30~50대)를 겨냥하되 한 판 30~60분, 세로 한 손 |
| 공유 장치 | 끝나면 '나만의 삼국사' 연대기 텍스트 복사 → 커뮤니티 인증 글 유도 |
| 신뢰 | 광고·결제·데이터 수집 없음 → 리뷰에서 반복될 장점 |
| 피처드 적합성 | 독창적 아트, 접근성(한 손 조작), 오프라인 — 애플 에디터가 선호하는 요소 |

## 아직 부족한 것 (상위권 전에 채워야 함)

1. **장수 원화** — 지금은 먹 실루엣. 피처드와 스크린샷 전환율에 가장 큰 영향. 최우선 투자 항목
2. **콘텐츠 양** — 시나리오 1개, 12성. 리뷰에서 "금방 끝난다"가 나올 수 있음 → 시나리오 2개 추가 또는 난이도·랜덤 장수 모드
3. **수익 모델** — 현재 없음. 권장: 유료(₩4,400~6,600) 또는 무료 + 시나리오 DLC. 광고는 브랜드와 맞지 않음
4. **실기기 품질** — Unity 에디터 실행 검증 전. 체크리스트의 품질 게이트를 먼저 통과해야 함

## 측정

데이터 수집이 없으므로 스토어 콘솔 지표만 본다: 노출→상세 페이지 전환율(목표 30%+), 상세→설치 전환율, 1일차 리뷰 평점(4.5+), 카테고리 순위 일별 기록.
